(Map) Projects
=================

Using the ``Save`` button under ``Map``, the currently open map can be
saved. The current view, the current visibility of the data layers, and the map markup are saved.

If additional (map) services were added to the map, they are inserted back into the map when the project is opened.

Advantages:

* The entire map, including additionally added (map) services, map markup, current geographic view, and configuration of the data layers (layers), is saved into a project.
* Is listed directly on the portal page (home page) under **My Projects** and can be opened from there.

Limitations:

* Projects should only be saved for smaller, time-limited projects. Since the underlying
  map services can also change, it cannot be guaranteed in the long term that saved
  projects will be displayed correctly.
