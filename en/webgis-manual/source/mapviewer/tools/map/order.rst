Draw Order
==================

With the draw order tool, the order of the topics can be switched. The topic in first place is shown at the very top, in the topmost map layer.
The topic that is at the last position in the list is also shown at the very bottom.

In addition, the transparency of the individual topics can also be set. The values *25%*, *50%*, *75%*, and *100%* are available for this.
