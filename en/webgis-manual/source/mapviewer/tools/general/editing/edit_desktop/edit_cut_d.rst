Splitting Geo-Objects (cut)
===========================

If you select a geo-object with a query tool, the table shows, among other things, the tool for splitting objects.

.. image:: img/teilen.png

.. note::
    Only line or polygon objects can be split!

If you select the split tool, the dialog opens, showing the attribute data of the geo-object.
The object is split along a cut line, which must be drawn.

.. image:: img/teilen_1.png

After defining the cut line and confirming with ``Split``, a dialog opens in which you must specify whether you want to keep the original object as a whole, or whether it should be deleted.

.. image:: img/teilen_2.png
