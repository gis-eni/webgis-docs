General
===========

WebGIS is a web application for displaying, querying, and editing geodata. Geodata is data with a geographic reference, i.e. a geographic location.
The data is offered in cartographic form as map(s).

The main application for displaying maps is the map viewer, which this manual was also designed for.

To begin with, however, a few basic concepts should be covered here, which should help in understanding the maps offered.
