Use Cases for UI Master Templates
======================================

In these templates, general elements can be set for all maps. This can be helpful
if a tool that was not previously available in all maps should suddenly be
available in all maps. This can generally also be solved by opening all maps in the
MapBuilder one after another and republishing them after adding the corresponding tool.

Examples:

* A specific general search service should be available via the quick search in all maps
* All maps should have the app menu
* Certain general tools such as *Share Map*, *Print*, *Download Map Image* should be available in all maps

Once *UI master templates* are defined, they also no longer need to be selected for new maps in the MapBuilder.
The corresponding elements are then automatically added in the map viewer.
