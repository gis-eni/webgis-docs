UI Master Templates
===================

*UI master templates* can be used to save *UI elements* and *tools* as a template, which is then
applied to all maps of a map category or to all maps of a portal page.

Elements from the template no longer need to be selected separately in the MapBuilder, but still
appear in all dependent maps.

.. note::
   **Caution:** When *UI master templates* are used, a map does not necessarily look the same
   as it was created in the MapBuilder. If you open the map via the map viewer (and not via
   the MapBuilder), the *UI elements* from the templates are additionally loaded.

A template can contain the following:

* **UI elements:** elements listed in the *MapBuilder* under ``User Interface (UI)`` (quick search, app menu, tabs)
* **Tools:** all tools listed in the *MapBuilder* under ``Tools (Toolbox)``
