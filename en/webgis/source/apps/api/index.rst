WebGIS API
==========

The **WebGIS API** is the heart of the WebGIS platform and offers powerful interfaces for accessing and interacting with map services. It provides a **REST API** through which users can request map and geodata. In addition, a **Javascript API** is also offered, which wraps the REST API calls and thus enables simplified integration into browser-based applications.

======================

Main Functions of the WebGIS API:
---------------------------------
- **REST API** for retrieving map services and geodata.
- **Javascript API** for the simple development of browser-based applications.
- Provision of map services based on configurations from the **WebGIS CMS**.
- Support for queries and visualizations of geodata.
- Flexibility for developers to create their own map applications and services.

Via the **WebGIS API**, map applications with various functions such as layers, queries, and geographic measurements can be built. It is the central interface for developers who want to build custom WebGIS applications.

======================

Using the WebGIS API:
---------------------------
- **Developers** who work with geodata and want to build their own web applications use the **REST API** or **Javascript API**.
- **Administrators** can use the API to define and adjust map services and their parameters via the **WebGIS CMS**.
- Through the XML files generated by the CMS, various map services and topics can be quickly configured and made available via the API.

Further details on the **Javascript API** can be found in the comprehensive documentation at (https://docs.webgiscloud.com/dev/index.html).
