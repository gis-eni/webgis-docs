**General**

**WebGIS DataLinq** is a powerful application for easily querying, analyzing, and visualizing data from various sources. The flexible architecture enables fast and direct access to databases, WebGIS REST APIs, GeoJSON, GeoRSS, and other formats.

With a clearly structured technical implementation – consisting of endpoints, queries, and views – **DataLinq** allows both read and write access to data. Results can be shown as raw data (JSON) or as formatted HTML views. Interactive charts and statistical evaluations enable well-founded data analysis.

**Main Features of WebGIS DataLinq**

- **Flexible Data Sources**
  Support for databases, APIs, and external applications.

- **Dynamic Queries & Analyses**
  Raw data or formatted reports for well-founded decisions.

- **Individual Permissions**
  Separate management of query and presentation rights.

- **Efficient Editing**
  Creation and adjustment of data records via interactive forms.

- **Helper Functions for Developers**
  Support via "DataLinqHelper" for rapid implementation.

Whether for detailed data evaluations, interactive visualizations, or as an interface between different systems – **WebGIS DataLinq** optimizes access to data and makes complex information easy to understand and access.
