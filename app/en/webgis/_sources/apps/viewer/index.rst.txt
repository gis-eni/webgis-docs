=============
WebGIS Viewer
=============

The WebGIS Viewer is a web-based application for displaying, analyzing, and editing geodata. It enables interactive map display, navigation, search, analysis, and editing directly in the browser.

Functions of the WebGIS Viewer
==============================

- **Map display** with various background maps and layers
- **Search and queries** across defined topics
- **Presentation variants** for controlling the visibility of layer groups
- **Editing tools** for editing geodata
- **Measurement and drawing tools** for analyzing spatial information
- **Dynamic content** via markers, layers, and external data sources

Control via URL Parameters
----------------------------

The WebGIS Viewer can be started with predefined settings via URL parameters. This enables targeted configuration for individual use cases.

The following functions can be controlled via URL parameters:

- **Map extent and navigation**

  Setting a specific map extent, zoom level, or coordinate system.

- **Layer control**

  Enabling or disabling individual layers, groups, or presentation variants.

- **Background maps**

  Selecting a specific basemap or overlays.

- **Queries and filters**

  Loading predefined queries with optional filter values.

- **Tools and interactions**

  Enabling measurement, drawing, or editing tools.

- **Dynamic content**

  Showing multiple markers or external layers.

By using these parameters, the WebGIS Viewer can be flexibly integrated into workflows or started with predefined settings for specific use cases.
