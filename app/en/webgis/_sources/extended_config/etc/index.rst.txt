=================
The etc Directory
=================

Some tools require extended configuration options that go beyond a *flat* configuration file. These specific configuration files are stored in the ``etc`` directory.

Generally, there is a dedicated subdirectory for each configurable tool. In these subdirectories, the installation package contains an ``example(s)`` folder that provides a sample configuration. This can be adapted to individual requirements.
