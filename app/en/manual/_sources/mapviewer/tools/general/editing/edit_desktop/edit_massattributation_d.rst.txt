Bulk Attribution
====================

| This tool is used to apply attribute data to several geo-objects at the same time. For this, these objects must be selected via a query.
| The *Bulk attribution (selected objects)* tool then appears in the query table.

.. image:: img/massenattribut.png

Clicking it opens the bulk-attribution dialog. Here it is important that a checkmark be set for the attributes to be changed, so that the field has a green background. Only then can values be entered, which are then applied to all objects.

.. image:: img/massenattribut_1.png

.. note::
    No *undo* is possible for bulk attribution!
