Editing in Desktop Layout
=========================

| Using the *Editing (Edit)* tool, geo-objects on the map can be created, changed, and deleted. Both the geometry and the attribute data of the object can be edited.
| Which topics and methods are available for *editing* is defined by the map author.
|
| Editing objects differs in the desktop layout from the mobile layout (see :ref:`edit_mobile`). Editing in the desktop layout is described in more detail in this chapter.
| If you select the *Editing (Edit)* tool in the toolbox, the following dialog opens:

.. image:: img/edit_uebersicht.png

| In the first row are the icons for different selection methods for geo-objects (this way, objects can be selected directly within this tool, without needing to switch to the *query* tool), and the icon for creating a new object.
| Below that is a drop-down menu, which can be used to switch between the editable topics of the map. For each topic, the editable geo-objects appear in the list below.
|
| The individual editing options are covered in more detail in the following sections.
