Deleting an Existing Object
===========================

To delete an existing object, the object must be selected, as with editing.
In the table that opens by querying the object, you will find the *Delete objects* tool among the table tools.


.. image:: img/loeschen.png

If you select this tool, the object to be deleted is shown in the preview, and you still have the option to cancel the delete action.

.. image:: img/loeschen_1.png

.. note::
   Deletion is performed directly on the geodatabase and is generally permanent. For some services, however,
   an undo function is also available (see the :ref:`undo_d` section).
