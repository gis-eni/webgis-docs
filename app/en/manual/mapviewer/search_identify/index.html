5 Search and Query

The (thematic) data shown on the map is not only shown cartographically but can also be searched and queried. The added value here is that in addition to the geographic location on the map, attribute data about objects can also be shown. For example, for a parcel, not only the location but also the cadastral community/parcel number, the area, and possibly also the owners are of interest.

Note

Not all topics that are visible on the map can also be queried. The administrator decides which topics are queryable and which attribute data is shown for these objects. Likewise, the map author determines which terms can be searched for in a detailed search.

The difference between search and query is clarified here:

  • Search: the user is at any map extent/scale and wants to find a geo-object. The search process is done by entering search terms into a search field or a search form.

  • Query: the user is at a map extent and wants information about one or more displayed geo-objects. This is usually done by clicking on a geo-object with the corresponding query tool.
