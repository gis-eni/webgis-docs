Map Viewer User Manual

This section is aimed at users of the WebGIS Viewer. It describes the basic operation and the available tools. The description is general and not written for specific workflows. Since a map author determines which content and tools are provided in a map, some applications may deviate from this description. The goal of this manual is to introduce the user to the basic concepts of operating the map viewer, which can then be applied in the various maps, each with different data sources and tools.

The “Default” color scheme was used for the illustrations in this manual. Here too, deviations may occur when map viewer instances are deployed outside of WebGIS Cloud.

The appearance of the map viewer also depends on the screen size of the end device. The WebGIS Viewer can be used both on a desktop and on mobile devices (tablet or phone). When a map is opened, the map viewer automatically decides which UI elements are shown on the end device. With a few exceptions, the available options are identical on all devices. This manual is aimed at desktop users who work with the map viewer in full-screen mode. Users on mobile devices will find the UI elements in somewhat different locations and in a slightly modified form.
