6 Tools

This section describes the tools of the map viewer. The organization of the tools follows a standard and can vary for different applications. Not all tools will be present in every map either.

The description shows the operation based on the desktop layout. On mobile devices with small displays, the functionality of the individual tools may appear somewhat restricted. However, the basic operating principle should be the same/similar.

The WebGIS framework also offers the option to create special tools that are not part of the map viewer’s standard set. These custom tools are not covered here.

In addition, the navigation tools are not described again here, since they were already described in the Navigating the Map section.
