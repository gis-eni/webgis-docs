Plugins
=======

Plugins are ready-made JavaScript *building blocks* that can be used for special tasks.
Using these plugins requires less knowledge of JavaScript.
Standard cases include, for example, a simple map with a search field for addresses. This case is
represented, for example, by the **Smartmap plugin**.
